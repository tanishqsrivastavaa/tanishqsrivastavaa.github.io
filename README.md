Personal GitHub Pages site, served at **[lexalytics.me](https://lexalytics.me)** (custom domain via `CNAME`).

## What's here

This repository backs the GitHub Pages deployment for my personal site. Site source and content are managed separately; this repo holds the Pages configuration and domain mapping.

## Local development

If you're rebuilding the site locally, any static site generator or plain HTML works — push to `master` and GitHub Pages handles the rest.
